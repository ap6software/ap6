# AP6 Language examples

These are the **AP6 Language** sources of demo applications that run live at https://ap6software.com/apps/.
An AP6 application is a **form** (the pages and every object on them, with their places and sizes), its **logic** (what happens on a click, a timer, a message), and, where needed, its **resources** (the ids of the pictures it uses).
The AP6 compiler turns these files into one compact binary package, and the AP6 core runs that package in the browser or on the desktop.

| Folder | Application | Files | Open the demo |
|---|---|---|---|
| [chess](chess) | Chess against the computer | `chess.form.ap6lang`, `chess.logic.ap6lang` | https://ap6software.com/apps/launch?id=game.chess |
| [game1](game1) | GAME1, a small game ported from an original Delphi game | `game1.form.ap6lang`, `game1.logic.ap6lang`, `game1.resources.ap6lang` (generated by the importer from the original artwork) | https://ap6software.com/apps/launch?id=game.game1 |
| [academy](academy) | AI Academy, an interactive course with the AP6 Helper | `ap6helper.academy.form.ap6lang`, `ap6helper.academy.logic.ap6lang`, `ap6helper.lessons.play.ap6lang`, and two generated blocks: `ap6helper.lessons.resources.ap6lang`, `ap6helper.animation.resources.ap6lang` | https://ap6software.com/apps/launch?id=edu.academy |

Notes:
- These files are published for **reading**: to show how an AP6 application is written. The AP6 compiler, core and hosts are not public, so the files cannot be built from this repository.
- The licence is the same as for the whole repository: see [../LICENSE.md](../LICENSE.md).
- Chess and GAME1 are the same as in the AP6 source tree, except for one comment line in `game1.logic.ap6lang` that named an internal folder.
- The Academy files are published **without comments** (the source tree's comments are internal working notes). Nothing else differs: the source tree's files and these files compile to the same application, byte for byte. The Academy is compiled in this order: animation resources, lessons resources, academy form, lessons play, academy logic.
